# opencode-statuskit 2.0.2

Distribution release. Plugin behavior is unchanged from 2.0.1.

## Highlights

- **Windows installer**: `install.ps1` and `uninstall.ps1`, no Node.js required.
- **Graceful installers**: `install.sh` no longer fails when Node is missing or `cli.json` is JSONC; it copies the plugins and prints the manual edit.
- **Tests**: the title state machine and the done slot logic are covered; installer tests run on Linux, macOS, Windows PowerShell 5.1, and PowerShell 7.
- **CI**: Ubuntu, macOS, and Windows on Node 22.
- **npm packages prepared**: `opencode-status-title` and `opencode-status-done` are ready for the second distribution phase, but are not published yet.
- **Docs**: Windows install, compatibility, troubleshooting, security, and upgrade notes.

## Tested

## Install

From the release tarball:

```sh
curl -fsSLO https://github.com/emmmdty/opencode-statuskit/releases/download/v2.0.2/opencode-statuskit-2.0.2.tar.gz
curl -fsSLO https://github.com/emmmdty/opencode-statuskit/releases/download/v2.0.2/SHA256SUMS
sha256sum -c SHA256SUMS        # macOS: shasum -a 256 -c SHA256SUMS
tar -xzf opencode-statuskit-2.0.2.tar.gz
cd opencode-statuskit-2.0.2
./install.sh
```

On Windows, verify the zip before extracting:

```powershell
Get-FileHash -Algorithm SHA256 .\opencode-statuskit-2.0.2.zip
# compare with the SHA256SUMS asset
```

Or with Git:

```sh
git clone --branch v2.0.2 --depth 1 https://github.com/emmmdty/opencode-statuskit.git
cd opencode-statuskit
./install.sh
```

Windows:

```powershell
# download and extract opencode-statuskit-2.0.2.zip, then:
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

`./install.sh --without-title` installs only the done plugin.

## Upgrade

Re-run the installer for the new version. It is idempotent and preserves unrelated `cli.json` keys.

## Uninstall

```sh
./uninstall.sh
```

```powershell
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1
```

## Known limits

- macOS TUI behavior in Terminal/iTerm2 is not yet verified.
- npm packages are prepared but not published.
- In tmux, the pane title changes; the outer terminal title depends on `set-titles`.
- The desktop app is not supported; this kit targets the terminal TUI.
